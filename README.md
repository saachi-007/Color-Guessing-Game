
# Color Guessing Game

## Overview

This is a simple Color Guessing Game made using Python. The computer selects a color, and the player has to guess it. The game shows the result and keeps track of the score and attempts.


## Features

- Easy to play
- Gives result after each guess
- Keeps score
- Gives limited attempts
- Allows the player to play again

## Technologies Used

- Python
- VS Code
- Git and GitHub

## How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the `main.py` file.
4. Run the Python program.
5. Enter your color guess when asked.

## Testing

The game was tested with correct and wrong guesses. Invalid colors, score, attempts, and the play again option were also checked.
