
# Problem Statement

The Color Guessing Game is a simple interactive game in which the computer randomly selects a color and the player tries to identify the correct color from the given options. The game provides feedback for each guess and keeps track of the player's score and number of attempts.

## Scope

The Color Guessing Game allows the player to guess a randomly selected color from a given list. The game checks the guess and shows whether it is correct or wrong. It also keeps track of the score and remaining attempts. The player can play the game again if they want.

## Target Users

The game is mainly designed for students and beginners who want to play a simple guessing game and learn basic programming concepts.

## High-Level Features

- Random color selection
- User color input
- Guess checking
- Score calculation
- Attempt tracking
- Play again option
